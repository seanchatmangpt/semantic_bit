# Refusal as Selection

If the activation state violates a defined boundary—such as setting mutually exclusive bits, or encountering an unrecognized combination—the selection rule must not fail silently.

Instead, the selection process itself resolves to a definitive outcome: **REFUSAL** or **ABEND**. The refusal to select an expected meaning is, paradoxically, a valid selection. The system transitions into a fault state rather than proceeding with ambiguity.
