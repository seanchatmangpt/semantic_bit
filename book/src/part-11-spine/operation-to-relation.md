# Operation to Relation

With an `Operation64` selected as the intended action, the Spine must now evaluate the context in which this operation will occur. This is managed by **Relation64**.

Every operation involves sources and targets, and depends on external realities (dependencies, authorities, compatibilities). The `Relation64` matrix bounds these connections.

Before the operation can be considered valid, all mandatory relations must be resolved. Are the dependencies met? Is the authority relation satisfied? Are there blocking relations? 

The traversal from Operation to Relation ensures that the action is not evaluated in a vacuum, but within the strict bounds of its required network of constraints.
