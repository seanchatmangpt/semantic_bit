# Closed Cognitive Field

A cognitive field must be **closed**. 

An open cognitive field is one where a machine might "decide" to proceed based on unspecified, external, or emergent factors. This is prohibited in the Semantic Bit philosophy.

A closed cognitive field means that the criteria for action are finite, explicitly enumerated, and completely contained within the `COG8` byte. If the machine proceeds, it is because the active bits in `COG8` perfectly match the admitted selection rule for the operation. If it refuses, it is because the bits do not match.

There is no "maybe." There is only the evaluation of the 8 bits.
