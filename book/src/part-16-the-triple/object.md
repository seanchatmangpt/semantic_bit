# Object

The **Object** is the identity or value that "receives" or "completes" the relation.

$$
\boxed{\textbf{The Object is the destination of the relation.}}
$$

## 16.7 Two Types of Objects

In a triple, the object can be:
1. **An Identity**: Another admitted subject (e.g., `User 123 owns Badge 456`).
2. **A Literal**: A bounded value like a number or a date (e.g., `Sensor 456 hasValue 22.5`).

## 16.8 The Boundary of the Object

If the object is an identity, it must be admitted. If it is a literal, it must be typed. We do not allow "Loose Objects" that escape the semantic boundary.
