# Triple Exercises

Apply the laws of the triple to the following scenarios.

## Exercise 16.1: Deconstruction

Given the narrative: "The temperature sensor in Room 101 reports a value of 72 degrees."
Deconstruct this into three triples. Use IDs where appropriate.

## Exercise 16.2: Predicate Selection

Which predicate best describes the relationship between a `User` and a `Group`?
- `sb:contains`
- `sb:memberOf`
- `sb:is`

Explain your choice using the Law of Direction.

## Exercise 16.3: Triple Coding

Write a Rust snippet that defines a `Triple` record and populates it with an ownership relation between a User (`ID: 1000`) and a Device (`ID: 5000`).

## Exercise 16.4: Fact vs. Claim

A user sends a packet claiming they are "Authorized". The system graph has no triples connecting the user to the "Authorized" role.
1. What is the selected condition?
2. Write the resulting receipt.
