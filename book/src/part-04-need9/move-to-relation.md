# Move to Relation

When splitting the field is insufficient or incorrect for the domain model, the ninth meaning can be captured by a **Move to Relation**. This strategy involves changing the ninth state from an active bit into a structured relation or pointer to another semantic entity.

Instead of asserting "this field has property X," the system asserts "this field has a defined relation to entity Y, which provides property X." Relation64 acts as a formalization of this concept.
