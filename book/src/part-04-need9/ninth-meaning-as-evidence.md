# The Ninth Meaning as Evidence

In an 8-bit semantic field, there are only eight possible independent active positions. When a system's semantics demands a ninth, it can no longer be carried as a simple multiplexed active bit. The ninth meaning transitions from an implicit state to explicit evidence.

This means that to test the condition of the ninth meaning, you must inspect evidence exterior to the primary 8-bit field, often realized through a receipt or a broader selection rule evaluating an adjacent field.
