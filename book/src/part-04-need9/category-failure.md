# Category Failure

Category Failure occurs when an engineer attempts to forcefully map nine distinct, independent categories of meaning into an 8-bit boundary. It is an engineering error characterized by:

- Loss of fidelity in meaning.
- Semantic overlap or conflict between two concepts forced into a single bit.
- Implicit behavior that cannot be audited through receipts.

To resolve a Category Failure, the design must yield to Need9 and restructure the semantics, typically by moving semantics to a relation or generating evidence.
