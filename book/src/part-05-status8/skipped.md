# SKIPPED

The **SKIPPED** status is the assertion of deliberate omission. The field was evaluated and explicitly ignored.

A field becomes `SKIPPED` when a selection rule determines that it is irrelevant to the current operation. It is not an error, nor is it invalid. It is simply a declaration that no action was required.

A `SKIPPED` status provides an audit trail, differentiating an intentionally ignored field from one that was accidentally missed.
