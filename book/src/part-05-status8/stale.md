# STALE

The **STALE** status is the assertion of temporal decay. The field was once valid, but time or subsequent events have rendered its meaning obsolete.

Data is often bound to a specific moment or condition. When that context shifts, the data becomes `STALE`. It is not corrupt, but it is no longer safe to use for current operations.

A `STALE` status forces the system to either refresh the field's data or handle it through an expiration protocol.
